# 缺口池答案模板（15 个缺口）

使用方式：在缺口池编辑器中按 title 找到对应缺口，填入 answer 与 boundary，并按 evidenceNote 关联证据 ID。证据 ID 由系统在知识文件上传后按节生成，可在生成结果页或导出中查看；evidenceNote 中的文件与节名均按本次拆分后的 4 个知识文件书写。填完保存后缺口所在模块回 draft，需重新批准。

## 一、可填答案的缺口（8 个）

### gap-03 · 当前正式价格表与优惠活动

- **answer**：源资料中的参考区间是：单纯眼袋主项目约 5k+，常见综合方案约 7k–9k，综合星钻精塑约 9k–1w+。实际方案会受眼袋、泪沟、凹陷和支撑情况影响，最终价格请以面诊后的当期正式报价为准；活动优惠也需要人工确认。
- **boundary**：动态信息。仅可复述参考区间，不得给出确定报价或承诺具体折扣；确切报价、优惠资格与活动条件转人工确认。
- **evidenceNote**：关联《动态信息_以当期为准.md》“5.1 标准价格回答”节生成的证据 ID；价格表与优惠说明见同文件“5. 价格与价值”节。

### gap-08 · 个体化恢复时间预测

- **answer**：体验和恢复存在个体差异。源资料描述恢复负担相对较轻：部分人 1–2 天轻微泛红、2–5 天轻微泛黄，一周左右痕迹逐渐不明显，也有个体第二天外观已不明显。项目采用分层舒适管理，过程中可与医生沟通；但不能保证无痛、无感觉、完全不红不肿或固定天数恢复，绷带拆除、护理及复查以医生给出的个体医嘱为准。
- **boundary**：个体差异大，不得承诺固定天数恢复，也不得保证不影响工作或社交；个体恢复预测只能由医生面诊和当次医嘱给出。
- **evidenceNote**：关联《动态信息_以当期为准.md》“6.1 源资料描述”与“6.2 可对外标准口径”两节生成的证据 ID；口径与《可对外口径.md》“FAQ-08：多久能恢复？”一致。

### gap-10 · 去脂肪后不凹陷的科学依据

- **answer**：项目理念是精准控量并保留必要支撑，以降低盲目过度去脂带来的不自然风险：只处理医生判断为多余膨出的部分，不追求把眼袋脂肪全部去除，并保留维持眼下自然饱满度和年轻感所需的支撑。但任何个体结果都不能作绝对保证，具体处理量和风险需由医生结合眼下结构评估。
- **boundary**：不得承诺“绝对不会凹”；源资料无长期随访数据，不得编造数据或引用不存在的研究；个体结果以医生评估为准。
- **evidenceNote**：关联《可对外口径.md》“FAQ-06：去脂后会不会凹？”节与“4. 核心技术与卖点”节（精准控量、保留支撑两行）生成的证据 ID。

### gap-04 · 医生项雄的执业资质与案例验证

- **answer**：源资料列出的项目主理医生为项雄，姓名可作为项目资料使用。其执业年限、案例数量、执业履历与“技术创研人”角色均需正式材料核验，不得转述为已核实事实；如需确认资质，应由人工提供可查验的执业信息。
- **boundary**：待核验。仅可转述“源资料列出主理医生为项雄”；不得给出年限、案例量、资质等结论性表述（“17 年”“案例 2w+”保持待核验，不写进答案）；资质确认转人工。
- **evidenceNote**：关联《可对外口径.md》“7. 医生与机构信息”节（“项目主理医生”行）生成的证据 ID；待核验状态依据见《待核验.md》“7. 医生与机构信息”节（项目角色／执业经历／专项经验行）。

### gap-14 · 机构完整地址和联系方式

- **answer**：源资料只写明成都锦江区、锦华万达附近，未填写机构全称和完整地址。请转人工客服提供当前准确地址与机构资质信息。
- **boundary**：动态信息。不得推测或补全地址、电话与预约方式；具体地址和预约安排转人工确认。
- **evidenceNote**：关联《动态信息_以当期为准.md》“7. 医生与机构信息”节（“城市／位置”行）生成的证据 ID。

### gap-06 · 终身保障的书面条款

- **answer**：源资料称项目含“终身保障”，但当前没有提供完整保障条款，因此不能解释为任何情况都免费处理，也不能等同于“终身不复发”。具体范围、条件、期限定义和除外事项需要人工提供正式书面条款。
- **boundary**：需正式书面条款支持。不得解释保障范围与兑现条件，不得承诺免费重做或永久不复发；具体条款转人工提供。
- **evidenceNote**：关联《待核验.md》“1. 项目基本信息”节（“基础保障”行）生成的证据 ID；口径与《可对外口径.md》“FAQ-14：‘终身保障’具体保障什么？”一致；禁止解释见《禁止承诺.md》“1. ‘基础保障’行的禁止解释”节。

### gap-11 · 适用于多种眼袋类型的具体范围

- **answer**：源资料主要面向脂肪型或遗传型眼袋，尤其是不笑时也能看到较明显半月形鼓包、皮肤弹性尚可的人。眼袋同时伴有轻中度泪沟、阴影或眼下断层的，可由医生面诊整体评估；泪沟不默认处理，要先区分真性和假性泪沟，能单做眼袋就单做，不需要的项目不增加。是否适合以及是否需要联合处理，必须由医生面诊判断。
- **boundary**：AI 不能判断个体是否适合，不得仅凭文字或照片做诊断；伴有泪沟、松弛等复合情况一律引导面诊，不在线定方案。
- **evidenceNote**：关联《可对外口径.md》“3. 用户需求与适用边界”节及“FAQ-03：主要适合什么样的眼袋？”“FAQ-04：熬夜后的浮肿能做吗？”“FAQ-05：有泪沟是否一定要一起做？”各节生成的证据 ID。

### gap-12 · SOFT舒适管理的具体操作内容

- **answer**：源资料描述 SOFT 分层缓释舒适管理为：表层先舒缓、深层再定点，并按敏感度和过程反馈调整节奏。注射麻药时可能有约 3 秒的短暂进针刺痛感，后续操作中部分人可能有酸胀、牵拉或压迫感，过程中可与医生沟通调整节奏。不能承诺百分百无痛或完全零感。
- **boundary**：源资料对操作细节描述有限，不得展开编造；不得承诺无痛、完全零感；个体感受差异以医生说明为准。
- **evidenceNote**：关联《可对外口径.md》“4. 核心技术与卖点”节（SOFT 舒适管理行）与“FAQ-07：过程疼不疼？”节生成的证据 ID；术中感受描述见《动态信息_以当期为准.md》“6.1 源资料描述”节。
